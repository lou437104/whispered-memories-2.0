whispered memories 2.0 

every portrait tells a story, every memory lives on.
welcome to whispered memories 2.0 a creative website dedicated to celebrating the love the personality and memories of our beloved animals through personalized digital portraits.

whether its celebrating a much loved companion or remembering a pet who has crossed the rainbow bridge. whispered memories aims to create meaningful heartfelt artwork that captures the unique bon between pets and there families.

about whispered memories 
whispered memories is a personal creative project combining a passion for animals digital illustration and web development 
each portrait is created with care and attention to detail celebrating the individual personality and character of every animal 
from playful companions to treasured memories of pets no longer with us every piece of artwork has its own story 
whispered memories 2.0 represents a fresh chapter for the project with completely redesigned website built from the ground up.

about the website 
whispered memories  2.0 is being independently designed and developed using 
html5 - website structure and content 
css3 - styling layout and responsive design 
javascript - interactive elements and functionality 
git & github - version control and project management 
visual studio code - development environment 
the website is being built entirely from scratch without using website builders or pre made template 

planned features 
the website aims to include :
homepage- an introduction to whispered memories 
about - the story and inspiration behind the project 
portfolio - a gallery showcasing completed artwork 
memorial portraits - artwork honouring pets who have passed awy 
custom portraits - information about personalized commissions 
contact - a way for visitors to get in touch 
responsive design - a layout that works across desktop tablet and mobile devices
accessibility - an inclusive and easy to navigate experience 

the features are planned and may change throughout the development

the meaning behind the name 
our pets leave paw prints on our hearts that stay with us long after they're gone 
whispered memories was created around the idea that those memories deserve to be celebrated and preserved 
wether through a portrait of a beloved companion or a tribute to a pet who has crossed the rainbow bridge the goal is to create artwork that holds a special meaning for its owner
